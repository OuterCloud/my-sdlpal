# 🎮 游戏数据文件目录

这个目录包含了《仙剑奇侠传》运行所需的所有游戏资源文件。

## 📁 文件说明

### 核心数据文件

- **`data.mkf`** - 游戏核心数据
- **`sss.mkf`** - 脚本数据
- **`word.dat`** - 文本字符串
- **`m.msg`** - 消息文本

### 图像资源

- **`abc.mkf`** - 敌人图像
- **`ball.mkf`** - 物品图像
- **`f.mkf`** - 战斗角色精灵
- **`fbp.mkf`** - 战场背景图像
- **`fire.mkf`** - 火焰效果
- **`gop.mkf`** - 地图数据
- **`map.mkf`** - 地图数据
- **`mgo.mkf`** - 场景精灵
- **`rgm.mkf`** - 角色头像
- **`rng.mkf`** - 动画数据

### 音频资源

- **`mus.mkf`** - 音乐文件
- **`midi.mkf`** - MIDI 音乐
- **`voc.mkf`** - 语音文件

### 其他

- **`pat.mkf`** - 图案数据
- **`setup.dat`** - 设置数据

## 📊 文件统计

```bash
# 查看文件大小
ls -lh

# 查看总大小
du -sh .
```

## 🔗 使用说明

这些文件通过符号链接被 `unix/` 目录引用，游戏运行时会自动读取。

**不要删除或移动这些文件！** 否则游戏将无法运行。

## 📝 文件来源

这些文件来自正版《仙剑奇侠传》游戏光盘。

根据 SDLPAL 项目说明：

- 这些文件属于大宇资讯（SoftStar）的知识产权
- 建议从 [Steam](https://store.steampowered.com/app/1546570/Sword_and_Fairy/) 购买正版游戏

## ⚠️ 注意事项

1. **不要修改这些文件** - 可能导致游戏崩溃
2. **保持文件名小写** - macOS/Linux 系统要求
3. **备份重要** - 建议备份整个目录

## 🔧 故障排除

### 游戏提示找不到文件

检查符号链接是否正确：

```bash
ls -la ../unix/*.mkf
```

如果链接断开，重新创建：

```bash
cd ..
for file in game_data/*; do
    ln -sf "../$file" "unix/$(basename $file)"
done
```

### 文件损坏

从备份或原始来源重新复制文件。
