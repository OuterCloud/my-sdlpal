# 🔮 SDLPAL 魔法技能说明

## ⚠️ 重要提示

**魔法 ID 必须使用游戏中实际存在的 ID！**

随意使用错误的 ID 会导致：

- 显示错误的魔法名称
- 游戏崩溃
- 存档损坏

**正确的方法**：

1. 先在游戏中正常学会魔法
2. 用 `view_magic.py` 查看魔法 ID
3. 然后才能安全地添加到其他角色或存档

## 🛠️ 使用工具

### 1. view_magic.py - 魔法查看器 ⭐ 推荐

```bash
cd cheat_tools
python3 view_magic.py ../unix/1.rpg
```

**功能**：

- 查看所有角色的魔法
- 只读模式，不会修改存档
- 安全可靠

**示例输出**：

```
🔮 李逍遥
----------------------------------------------------------------------
  槽位  5: 魔法ID = 296 (0x0128)

🔮 赵灵儿
----------------------------------------------------------------------
  槽位  0: 魔法ID = 312 (0x0138)
  槽位  1: 魔法ID = 316 (0x013C)
  ...
```

### 2. add_magic_safe.py - 安全魔法添加器

```bash
cd cheat_tools
python3 add_magic_safe.py ../unix/1.rpg
```

**功能**：

- 使用已知的真实魔法 ID
- 自动备份
- 交互式添加

**使用步骤**：

1. 运行工具
2. 查看已知魔法 ID 列表
3. 输入要添加的魔法 ID
4. 进入游戏验证

### 酒神是什么？

- **类型**: 李逍遥专属技能
- **学习时机**: 蜀山剧情，酒剑仙传授
- **特点**: 强力攻击技能，可能有使用次数限制

### 如何找到酒神的魔法 ID？

**推荐方法**：

1. 在游戏中正常流程到达蜀山
2. 学会酒神技能
3. 保存游戏
4. 运行查看器：
   ```bash

   ```

6. 记录下来，以后可以直接添加到其他存档

### 关于使用次数

如果酒神有固定的使用次数限制：

1. **在游戏中使用酒神**
2. **记录使用前后的次数**（例如：5 次 → 4 次）
3. **在存档中搜索这个数值**：

   ```python
   import struct
   with open('unix/1.rpg', 'rb') as f:
       data = f.read()

   # 搜索值5
   for i in range(len(data)-1):
       value = struct.unpack_from('<H', data, i)[0]
       if value == 5:
           print(f"找到5在偏移: 0x{i:04X}")
   ```

4. **修改并验证**

## 📐 技术信息

### 魔法数据结构

- **PLAYERROLES 基址**: 0x01FC
- **rgwMagic 偏移**: +384 (相对于基址)
- **数据结构**: `WORD rgwMagic[32][6]`
  - 第一维: 32 个魔法槽位
  - 第二维: 6 个角色

### 计算公式

```
魔法偏移 = PLAYERROLES基址 + 384 + 魔法槽位 * 12 + 角色索引 * 2

例如：
- 李逍遥槽位0 = 0x01FC + 384 + 0*12 + 0*2 = 0x037C
- 李逍遥槽位1 = 0x01FC + 384 + 1*12 + 0*2 = 0x0388
- 赵灵儿槽位0 = 0x01FC + 384 + 0*12 + 1*2 = 0x037E
```

### 角色索引

- 0 = 李逍遥
- 1 = 赵灵儿
- 2 = 林月如
- 3 = 阿奴
- 4 = 刘晋元
- 5 = 盖罗娇

## 💡 使用建议

1. **先查看再添加**

   - 用 `view_magic.py` 查看其他角色的魔法
   - 选择合适的魔法 ID
   - 用 `add_magic_safe.py` 添加

2. **测试验证**

   - 每次添加后进游戏验证
   - 确认魔法名称和效果正确
   - 如果不对，恢复备份重试

3. **记录 ID**

   - 把有用的魔法 ID 记录下来
   - 方便以后使用

4. **备份存档**
   - 修改前务必备份
   - 工具会自动创建备份，但手动备份更安全

## ⚠️ 常见问题

### Q: 为什么添加的魔法显示不正确？

A: 使用了错误的魔法 ID。必须使用游戏中真实存在的 ID（295-400 范围）。

### Q: 可以给李逍遥添加赵灵儿的魔法吗？

A: 技术上可以，但某些魔法可能有角色限制。建议先测试。

### Q: 魔法槽位满了怎么办？

A: 每个角色最多 32 个魔法槽位。如果满了，需要先删除一些魔法。

### Q: 如何删除魔法？

A: 手动编辑存档，将对应槽位的魔法 ID 改为 0。或者恢复备份。
