# 穿墙功能演示

## 🎯 目标

为 SDLPAL 游戏添加穿墙功能，让玩家可以穿过墙壁和障碍物。

## 📋 实现步骤

### 第一步：了解需求

用户询问："我可以穿墙吗"

### 第二步：分析代码

1. 查看 `scene.c` 文件
2. 找到碰撞检测函数 `PAL_CheckObstacleWithRange()`
3. 理解碰撞检测机制

### 第三步：设计方案

提供三种实现方法：

1. 始终开启穿墙（最简单）
2. 按键切换穿墙（更灵活）
3. 配置文件控制（最灵活）

### 第四步：创建工具

1. `enable_noclip.py` - 自动化脚本
2. `patch_noclip.sh` - Bash 版本
3. 详细文档和使用指南

## 📊 技术细节

### 修改前的代码

```c
BOOL
PAL_CheckObstacleWithRange(
    PAL_POS         pos,
    BOOL            fCheckEventObjects,
    WORD            wSelfObject,
    BOOL            fCheckRange
)
{
   int x, y, h, xr, yr;
   // ... 复杂的碰撞检测逻辑 ...

   if (PAL_MapTileIsBlocked(x, y, h, PAL_GetCurrentMap()))
   {
      return TRUE;  // 有障碍
   }

   // ... 更多检查 ...

   return FALSE;  // 无障碍
}
```

### 修改后的代码（方法一）

```c
BOOL
PAL_CheckObstacleWithRange(
    PAL_POS         pos,
    BOOL            fCheckEventObjects,
    WORD            wSelfObject,
    BOOL            fCheckRange
)
{
   // NOCLIP PATCH: Always return FALSE to disable collision
   return FALSE;

   // 下面的代码不会执行
   int x, y, h, xr, yr;
   // ...
}
```

### 效果

- 所有碰撞检测都返回 FALSE（无障碍）
- 玩家可以穿过任何墙壁和障碍物
- 简单有效

## ⚠️ 注意事项

### 可能的问题

1. **卡住**：穿到某些区域可能无法返回
2. **跳过剧情**：可能错过重要的触发点
3. **地图边界**：穿出地图可能导致崩溃

### 解决方案

1. 使用前备份存档
2. 只在探索时使用
3. 遇到问题读取之前的存档
