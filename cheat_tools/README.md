# 🎮 SDLPAL 修改器工具

> 仙剑奇侠传存档修改工具 - 完全非侵入式，只修改存档文件

---

## 🚀 快速开始

### 1. 修改属性（体力、真气、武术等）

```bash
cd cheat_tools
python3 sdlpal_cheat_final.py ../unix/1.rpg
```

选择 `1` 一键拉满所有属性，或选择 `2` 自定义修改。

### 2. 查看魔法

```bash
python3 view_magic.py ../unix/1.rpg
```

查看所有角色学会的魔法及其 ID。

### 3. 添加魔法

```bash
python3 add_magic_safe.py ../unix/1.rpg
```

输入已知的魔法 ID 来添加（必须是游戏中真实存在的 ID）。

### 4. 启用穿墙功能 🆕

```bash
python3 enable_noclip.py
```

自动修改源代码并重新编译，启用穿墙功能。

## 💡 重要提示

### 使用前必读

1. **务必备份存档**

   ```bash
   cp unix/1.rpg unix/1.rpg.backup
   ```

2. **魔法 ID 必须正确**

   - 不要随意使用未知 ID
   - 先用 `view_magic.py` 查看真实 ID
   - 错误的 ID 会导致显示错误或崩溃

3. **装备加成**
   - 修改武术为 999 → 游戏显示 1001（装备+2）
   - 修改防御为 999 → 游戏显示 1008（装备+9）
   - 修改身法为 999 → 游戏显示 1002（装备+3）

### 恢复存档

```bash
cp unix/1.rpg.backup unix/1.rpg
```

## 🍶 关于酒神技能

酒神是李逍遥的专属技能，需要在蜀山学习。

**如何找到酒神 ID**：

1. 在游戏中正常学会酒神
2. 保存游戏
3. 运行 `python3 view_magic.py unix/1.rpg`
4. 查看李逍遥新增的魔法 ID
5. 记录下来，以后可以直接添加

**关于使用次数**：
如果酒神有使用次数限制，需要：

1. 使用酒神前后记录次数（如：5 次 →4 次）
2. 在存档中搜索这个数值
3. 找到后即可修改
