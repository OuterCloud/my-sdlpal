================================================================================
SDLPAL 修改器工具 - 快速使用指南
================================================================================

📁 工具列表
================================================================================

1. sdlpal_cheat_final.py  - 李逍遥属性修改器（一键拉满）
2. modify_role.py         - 任意角色属性修改器（支持翻倍/自定义）
3. view_magic.py          - 魔法查看器（只读，安全）
4. add_magic_safe.py      - 魔法添加器（使用真实ID）
5. enable_noclip.py       - 穿墙功能启用器 🆕

================================================================================
🚀 常用操作
================================================================================

【修改李逍遥属性 - 一键拉满】
    cd cheat_tools
    python3 sdlpal_cheat_final.py ../unix/1.rpg
    输入: 1  (一键拉满)
    输入: 5  (保存退出)

【修改其他角色属性 - 全部翻倍】
    cd cheat_tools
    python3 modify_role.py ../unix/1.rpg
    选择角色编号 (0-5)
    选择: 1  (全部翻倍)
    输入: y  (确认)

【查看所有角色的魔法】
    cd cheat_tools
    python3 view_magic.py ../unix/1.rpg

【添加魔法到李逍遥】
    cd cheat_tools
    python3 add_magic_safe.py ../unix/1.rpg
    输入魔法ID (如: 312)

【启用穿墙功能】🆕
    cd cheat_tools
    python3 enable_noclip.py
    选择: 1  (始终开启穿墙)
    等待编译完成
    cd ../unix && ./sdlpal

================================================================================
💡 重要提示
================================================================================

1. 备份存档
   cp unix/1.rpg unix/1.rpg.backup

2. 恢复存档
   cp unix/1.rpg.backup unix/1.rpg

3. 装备加成
   游戏显示值 = 基础值 + 装备加成
   - 武术: 装备+2
   - 防御: 装备+9
   - 身法: 装备+3

4. 魔法ID
   - 必须使用真实ID（295-400范围）
   - 错误ID会导致崩溃
   - 先用 view_magic.py 查看

5. 数值限制
   - 建议不超过9999
   - 过大的值可能导致问题

🍶 关于酒神
================================================================================

酒神是李逍遥的专属技能，需要在游戏中学会后才能知道ID。

查找步骤：
1. 在游戏中学会酒神
2. 保存游戏
3. python3 view_magic.py ../unix/1.rpg
4. 查看李逍遥新增的魔法ID
5. 记录下来，以后可以直接添加

🚶 穿墙功能说明 🆕
================================================================================

穿墙功能可以让角色穿过墙壁和障碍物。

⚠️  警告：
  - 可能导致卡住或跳过剧情
  - 使用前务必备份存档
  - 需要修改源代码并重新编译

快速启用：
  cd cheat_tools
  python3 enable_noclip.py
  选择模式 1（始终开启）

恢复正常：
  再次运行 enable_noclip.py
  选择恢复原始版本

详细说明请查看：
  - enable_noclip.md（技术文档）
  - 穿墙使用指南.txt（快速指南）
